# Mention people with @ (#146)

## Built

- Typing `@` in the room or thread composer (at the start or after a space)
  opens a list of the room's members above the field: picture, name and
  Matrix ID, names starting with the typed text first, yourself left out.
  ↑ ↓ choose, Return or Tab picks, Escape closes, a click picks.
- Picking writes `@Name ` and remembers the person for that room's composer
  (kept with the room's draft) or the open thread.
- On send, core's new `compose_with_mentions` turns each remembered `@Name`
  still in the text into a matrix.to link in the formatted body and lists
  the people in `m.mentions`, as Element does; the plain body stays as
  typed. A mention deleted from the text is dropped; without mentions the
  message is composed exactly as before. Replies keep the SDK's mention of
  the quoted sender.
- Preview: `--preview-mention`.

## Verified

- Compile: strict workspace Clippy.
- Offline tests: core unit test (links, longest label first, escaping,
  `m.mentions`, dropped mentions); app tests for the query parsing,
  candidate order and the composer flow (type "@sa", Return, "@Sam " and
  the remembered mention). 205 app tests pass.
- Local Synapse: `run.sh threads` (send, send_reply, thread replies) passes
  with the new send signature.
- Capture of the preview reviewed.

## Not verified

- How Element shows the mention (pill and notification) for a live message.
- Editing a message does not add mentions yet; a failed send restores the
  text but not the remembered people.
