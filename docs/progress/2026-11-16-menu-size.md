# Larger, readable menu items (#149)

## Built

- Every context and dropdown menu (account, room, space, message, composer
  Format) now uses the body text size, 13 pt, on 22.75 pt rows, with icons
  sized to match. Upstream GPUI Kit draws menu items at about 11 pt with
  12 pt icons and has no size option.
- This is a patch of gpui-component 0.9.1 in `vendor/` (see
  `vendor/README.md`), applied through `[patch.crates-io]` like the
  libwebrtc patch. The account, room and space menus also got icons earlier
  in this batch.

## Verified

- Compile: strict workspace Clippy with the patched crate. Offline tests:
  207 app tests pass.
- Capture of `--preview-accounts-menu` reviewed.

## Not verified

- Linux and Windows menus beyond CI; long labels in narrow windows.
